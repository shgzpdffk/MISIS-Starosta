# МИСИС · Староста

Telegram-бот и Mini App для учебной группы: расписание, посещаемость, объявления и обращения к старосте. Независимый студенческий проект; не официальный сервис НИТУ МИСИС.

**Статус:** beta · **Версия:** 0.3.0 · **Лицензия кода:** [MIT](LICENSE)

## Возможности

- Создание групп и вступление по приглашению, роли старосты и студента, приоритетная группа.
- Профиль с настоящими именем и фамилией, аватар Telegram и календарь посещаемости.
- Импорт расписания МИСИС с предпросмотром, недели, подгруппы, ручные занятия и каникулы.
- Журнал, личные опросы, причины пропусков с вложением, статистика и выгрузка Excel.
- «Буду на всех парах»: автоматические отметки за текущий день и отключение повторных опросов.
- Объявления с датой публикации, архивом и подтверждением ознакомления.
- Карточка группы с текстом, одним фото и ссылками; личные обращения к старосте.
- Категории уведомлений, тихие часы, темы оформления и крупный текст.
- Сообщения об ошибках на сервере с автором и временем обращения.

## Быстрый запуск

Нужен **Node.js 24+**. Для разработки также нужны npm и **Python 3.10+**. Сервер и бот используют стандартную библиотеку Node.js; npm-пакеты нужны только для разработки. Python используется для загрузки Excel-расписаний.

```sh
npm ci
cp .env.example .env
npm start
```

Откройте <http://127.0.0.1:3000>. Без запуска из Telegram работает демо с вымышленными данными в localStorage. Демо не имеет доступа к серверным группам.

Для загрузки расписаний при запуске без Docker создайте Python-окружение:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
```

Укажите в `.env` значение `PYTHON_BIN=.venv/bin/python`. В Windows используйте `.venv\Scripts\python.exe` и скопируйте `.env.example` средствами своей оболочки.

Официальные расписания **не включены в репозиторий**. Староста загружает их в приложении через «Расписание → Подключить расписание МИСИС → Загрузить с сайта МИСИС». Локально каталог также можно подготовить командой:

```sh
.venv/bin/python scripts/misis.py --output public/misis-data.json
```

Этот файл исключён из Git. Для тестов загрузка с сайта не требуется.

## Запуск бота

1. Создайте бота в [@BotFather](https://t.me/BotFather).
2. Разверните приложение на сервере с HTTPS: [Amvera](AMVERA.md) или [Docker Compose](docs/OPERATIONS.md).
3. Задайте `BOT_TOKEN`, `APP_URL` с HTTPS-адресом приложения и `BOT_ENABLED=true` в окружении сервера. Не помещайте токен в исходники или GitHub.
4. Напишите боту `/start`. Бот устанавливает кнопку меню «Моя группа». Main Mini App можно настроить в BotFather с тем же адресом.
5. Откройте приложение, заполните профиль, создайте группу, проверьте импорт расписания и пригласите студентов.

Каждый участник должен сам начать диалог с ботом, чтобы получать уведомления. Используется long polling: запускайте **один экземпляр** приложения на один токен и SQLite-базу. Активный webhook этого бота должен быть отключён перед запуском.

## Проверки и участие

```sh
npm run check
.venv/bin/python -m ruff check .
.venv/bin/python -m ruff format --check .
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
```

`npm run check` проверяет форматирование, ESLint, тесты Node.js и сборку статического превью. Форматирование: `npm run format` и `.venv/bin/python -m ruff format .`.

Публикация своего репозитория: [docs/PUBLISHING.md](docs/PUBLISHING.md).

Правила работы: [CONTRIBUTING.md](CONTRIBUTING.md). Устройство проекта и границы доступа: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Проверки автоматически запускаются в GitHub Actions для pull request и push в `main`.

## Структура

```text
public/       интерфейс и общая логика, работающая в браузере и Node.js
server/       HTTP API, проверка Telegram, SQLite, очередь и бот
scripts/      импорт расписания, сборка, служебные утилиты
tests/       тесты на вымышленных данных без обращения к внешним сервисам
docs/        архитектура, эксплуатация и публикация
.github/      CI и шаблоны предложений и ошибок
```

## Ограничения beta

- Импортер поддерживает два известных табличных формата МИСИС. Ручные XLSX-таблицы ИБО и сложные ограничения по датам могут требовать ручного ввода. Нераспознанные строки показываются перед импортом; тип первой недели проверяет староста.
- Каталог обновляется по запросу. Обновление каталога не меняет расписание группы до подтверждения импорта. Изменения расписания внутри текущего дня требуют сверки отметок.
- «Буду на всех парах» применяется к расписанию в момент нажатия. Уже заданные индивидуальные отметки сохраняются; добавленные позже пары нужно проверить отдельно.
- Доставка Telegram работает по принципу at-least-once: при неопределённом результате запроса возможен повтор сообщения. SQLite и локальная очередь рассчитаны на один экземпляр приложения.
- Файлы до 2 МБ сохраняются в базе. У группы есть ограничение 25 МБ для её JSON-состояния; это не общий лимит всей базы или вложений обращений. Объём диска нужно контролировать.
- Сессия Telegram действует один час; после истечения нужно открыть Mini App заново. «Настоящее имя» вводит пользователь, документальная проверка личности не выполняется.
- Есть локальные автоматические тесты; они не заменяют проверку с настоящим ботом и на целевом сервере. Docker-сборка проверяется отдельным заданием CI.
