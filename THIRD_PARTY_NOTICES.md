# Сторонние компоненты и данные

Лицензия MIT в корне относится к коду этого проекта и его документации. Она не выдаёт права на внешние данные, названия или сервисы.

| Компонент                       | Использование                                                                        | Источник                                                               |
| ------------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| МИСИС                           | Страница со ссылками на публичные расписания; файлы загружаются оператором           | <https://misis.ru/students/schedule/>                                  |
| Telegram                        | Bot API и Web App SDK, SDK загружается с домена Telegram                             | <https://core.telegram.org/bots/webapps>                               |
| Google Fonts                    | Внешняя загрузка шрифта интерфейса, если доступна; системный fallback при отсутствии | См. `public/styles.css`                                                |
| Node.js и SQLite                | Исполнение сервера и хранение данных                                                 | <https://nodejs.org/>                                                  |
| xlrd, openpyxl                  | Чтение XLS/XLSX; версии зафиксированы в `requirements.txt`                           | <https://pypi.org/project/xlrd/>, <https://pypi.org/project/openpyxl/> |
| Prettier, ESLint, globals, Ruff | Инструменты разработки; не нужны работающему боту                                    | `package-lock.json`, `requirements-dev.txt`                            |
| Docker base image, gosu, Caddy  | Контейнерное размещение и HTTPS                                                      | `Dockerfile`, `compose.yaml`                                           |

В открытом репозитории нет выгрузки расписания университета, рабочих баз или пользовательских вложений. Для парсера используются синтетические тестовые таблицы. Локальный `public/misis-data.json` и постоянный каталог сервера исключены из Git.

Зависимости сохраняют собственные лицензии. При распространении образов, зависимостей или дополнительных ресурсов соблюдайте их уведомления и условия; не обозначайте их автоматически как собственный код MIT.
