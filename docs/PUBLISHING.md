# Публикация на GitHub

Рекомендуемое название репозитория — `misis-starosta`. Архив исходников нужно распаковать: на GitHub публикуется содержимое проекта, а не один ZIP-файл.

## Через терминал

Откройте папку подготовленных исходников. В GitHub создайте пустой **Public**-репозиторий; не добавляйте автоматически README, лицензию и .gitignore — они уже есть.

```sh
git init -b main
git add .
git diff --cached --stat
git status --short
```

Проверьте список: там не должно быть `.env`, базы, файлов пользователей, `node_modules`, локального каталога МИСИС или выгрузок обращений. Затем:

```sh
git commit -m "Prepare open-source beta release"
git remote add origin https://github.com/YOUR_USERNAME/misis-starosta.git
git push -u origin main
```

Замените `YOUR_USERNAME` своим именем GitHub, либо используйте точный адрес нового репозитория. GitHub предложит авторизоваться доступным у вас способом; токен бота для этого не нужен. Если Git просит имя и email автора коммита, задайте свои значения; можно использовать предоставленный GitHub noreply-адрес.

Вместо терминала можно использовать GitHub Desktop: **Add local repository** или **Create repository from existing folder**, затем **Publish repository**, выбрав публичную видимость. Убедитесь, что скрытые файлы `.github`, `.gitignore`, `.editorconfig` и `.env.example` тоже входят в публикацию.

## После первого push

- В разделе Actions дождитесь результата `Checks`: проверки кода и контейнера.
- В Settings → Security включите private vulnerability reporting, если доступно; порядок сообщений описан в `SECURITY.md`.
- При необходимости включите защиту основной ветки с обязательным pull request и проверками CI.
- Проверьте отображение README и MIT-лицензии.

В репозитории нет заданного владельца GitHub, удалённого адреса или токенов. Публикация не настроена автоматически и не обновляет ваш сервер Amvera сама по себе.

При последующих изменениях `.gitignore` не удалит файлы, которые уже были добавлены в Git раньше. Если секрет попал в историю, прежде всего отзовите его; простого удаления из последнего коммита недостаточно.
